# Plotline

Movie, series and book recommendations shaped by your taste, with trailers, IMDb and reader ratings, community reviews, and where to watch or read. New releases are added automatically.

## Run it locally

```bash
python tools/serve.py
```

Then open http://localhost:8000. (Opening `index.html` directly won't work; browsers block loading the catalog from `file://`.)

## What's inside

| Path | What it is |
| --- | --- |
| `index.html`, `css/`, `js/` | The site. Plain HTML/CSS/JS modules, no build step. |
| `data/seed.json` | The hand-picked starter catalog (with moods/taste tags). Edit freely. |
| `data/catalog.json` | Generated by the sync: seed + auto-added releases, posters, trailers, popularity. |
| `tools/sync.py` | Finds new releases and enriches the catalog. |
| `.github/workflows/sync.yml` | Runs the sync every day and commits the result. |
| `firebase/` + `firebase.json` | Firestore security rules/indexes and hosting config. |

## How new releases get added automatically

`python tools/sync.py` (and the daily GitHub Action) does this, with no API keys required:

1. **Discovers** titles trending on Wikipedia over the last week, plus new entries in release categories (`2026 films`, `2026 American television series debuts`, `2026 novels`, …).
2. **Keeps** films, series, seasons and books released in the last ~150 days or coming in the next ~120 days.
3. **Enriches** each one: summary, poster/cover, genres, cast and network (Wikipedia/Wikidata), official trailer and backdrop (YouTube), show posters and new/upcoming seasons (TVmaze), covers and reader ratings (Open Library).
4. **Ranks** everything by real 30-day page views, so "Top 10 right now" reflects what people are actually looking up.

Titles are never removed; the catalog grows over time. On the site, new arrivals get a **NEW** badge, upcoming ones go to **Coming soon**, new seasons get a **NEW SEASON** badge, and returning visitors see "N new releases since your last visit".

Useful flags: `--days 150 --ahead 120 --max-new 40 --no-discover --refresh`.

## What you need to set up

### 1. Firebase: real sign-in + shared ratings & reviews (required to go live)

Without it, the site runs in **demo mode**: sign-in is simulated, and the reviews/ratings shown are clearly labelled samples stored in your browser. To collect real ratings from everyone:

1. Create a project at https://console.firebase.google.com (the free Spark plan is enough to start).
2. **Project settings → Your apps → Add web app**, then paste the config object into `CONFIG.firebase` in `js/config.js`.
3. **Authentication → Sign-in method**, enable **Email/Password** and **Google** (both free).
4. **Authentication → Settings → Authorized domains**: add the domain you host on.
5. **Firestore Database → Create database** (production mode). Then open its **Rules** tab, paste in the contents of `firebase/firestore.rules`, and click **Publish**.
6. The first time someone opens a title page, the browser console shows a Firestore link to create the reviews index. Open it and click **Create** (or add the two indexes from `firebase/firestore.indexes.json` under **Firestore → Indexes**).

If you later install the Firebase CLI, `firebase deploy --only firestore` does steps 5–6 in one go.

The rules allow one review per person per title, let only the author edit it, and only allow like counts to change by ±1 together with a like record, so counts can't be inflated.

### 2. Hosting + daily auto-updates

Push this folder to a GitHub repo, then either enable **GitHub Pages** (Settings → Pages → deploy from branch) or connect the repo to Netlify, Vercel or Firebase Hosting (`firebase deploy --only hosting`). The included workflow runs the sync daily and pushes `data/catalog.json`, and your host redeploys automatically. You can also trigger it from the **Actions** tab.

### 3. Optional keys (add as GitHub Actions secrets)

| Secret | Free? | What it adds |
| --- | --- | --- |
| `TMDB_API_KEY` | Yes (themoviedb.org → Settings → API) | Sharper posters & backdrops, official trailer list, **live where-to-watch per region** (powered by JustWatch). Recommended for a public launch. |
| `OMDB_API_KEY` | Free tier, 1,000/day (omdbapi.com) | **Live IMDb ratings** for every title. |

Without OMDb, the IMDb ratings in `seed.json` are a hand-entered snapshot, and auto-added titles link to IMDb without showing a score.

## Notes before launching publicly

- Text summaries from Wikipedia/TVmaze are CC BY-SA and are credited on the page. Posters and trailers belong to their studios/publishers; using TMDB (with its required attribution) is the cleanest route for artwork at scale.
- Without a TMDB key, trailer lookup scrapes YouTube search results, which works but is fragile and may be rate-limited from CI servers. With a key, trailers come from TMDB's official video list.
- Streaming availability changes constantly; every title links to JustWatch for live options in the visitor's region.
